# CADENIQUE assets

- `branding/logos/`: logo principal, versions claire/sombre et logo monochrome.
- `branding/icons/`: icone de l'application et favicon.
- `images/`: images utilisees dans les ecrans de l'application.
- `fonts/`: fichiers de polices personnalisees.
- `screenshots/`: captures de reference pour le design.

Utiliser des noms explicites, par exemple `cadenique-logo-dark.png` ou `cadenique-icon.png`.
